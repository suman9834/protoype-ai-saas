# EcoLedger AI — Carbon & ESG SaaS Prototype

This is a static UI prototype for the startup idea discussed in chat.

## Included
- Dashboard
- Carbon calculator
- ESG report preview
- AI sustainability insights
- Responsive dark/green SaaS interface

## Run
Open `index.html` in a browser.

## Important
The emission factors in this prototype are illustrative only. They must be replaced with verified, jurisdiction/standard-specific factors before using the product for real carbon accounting or compliance reporting.
